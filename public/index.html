CONNECTION

Geminiに接続

ご自身のGoogle CloudプロジェクトとAPIキーを使います。キーはこのタブのメモリだけに保持されます。

接続と保存について

写真と例文は処理時にGoogleへ送信され、API利用料が発生する場合があります。キー・写真・結果は自動保存しません。タブを閉じる前にCSVまたは作業JSONを保存してください。

APIキー方式では、利用先のプロジェクトはキーに紐付いたものです。入力したIDとの一致は自動検証できません。Gemini 2.5の利用可否はプロジェクトによって異なります。

SOURCE PHOTO

元写真

回転は抽出前のみ変更できます。横方向・縦方向にスクロールして確認できます。

使い方

  1. API設定

    Google CloudプロジェクトIDと、選択した接続方式に対応するAPIキーを入力します。Vertex AIはサービスアカウントに紐付いたキーを使います。通常の制限なしキーだけで動くとは限りません。

  2. 写真を追加・抽出

    英文と訳が読める写真を選びます。①②は例文番号、区切られたまとまりはブロック番号になります。短い語句も抽出します。

  3. AIの疑問点を確認

    「要確認」の行を選び、元写真を拡大して確認します。候補の適用や手動編集をしたあと「手動確認済みにする」を押します。

  4. 8列のCSVを保存

    英文 / 日本語訳 / 写真名 / ページ番号 / ブロック番号 / 例文番号 / 状態 / 確認理由。全行を保存します。空欄の例文番号は空欄のままです。

作業JSONは写真・APIキーを含みません。再開後は必要に応じて同じ名前の写真を追加すると照合できます。CSVはExcel向けのUTF-8 BOM付きです。
